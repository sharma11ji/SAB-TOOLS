# SAB TOOLS
Smart Tools for Carpenters & Furniture Workers.

## Stack
React, Vite, JavaScript, Firebase Auth, Firestore, Storage architecture and PWA.

## Run
Copy .env.example to .env, add Firebase Web App values, then run npm install, npm run dev and npm run build.

## Firebase
Enable Google and Email/Password authentication, create Firestore, and deploy firestore.rules. Never put Firebase Admin credentials in the frontend.

## Included
Mobile-first application shell, Google sign-in, cloud calculator history, search, CFT, Board Feet, Area, Volume and Waste calculators, responsive UI and installable manifest foundation.
